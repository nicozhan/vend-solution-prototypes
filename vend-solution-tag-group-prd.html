Product Requirements Document

标签&分组管理

在现有平台基础上新增「标签&分组管理」能力，并将其接入预包装商品、现制商品与点位三类业务对象的列表与筛选；同时统一商品页的列标题与搜索口径。本文档以当前可交互原型为准，红色文字表示相较旧版的变更点。

版本 v1.0 日期 2026-11-24 模块 系统设置 / 商品 / 点位 状态 待评审 原型 vend-solution-reports.html
01

背景与目标

平台原先的标签与分组分散在各业务对象的设置页中，缺少统一的集中管理入口；商品列表也缺少按分组、标签快速筛选与识别的能力，运营人员难以批量运营同类商品。

本需求新增「标签&分组管理」作为集中管理控制台，并在预包装商品、现制商品、点位三个业务页面上提供入口与可视化展示，实现「一处管理、多处生效」。

目标一
集中管理
分组与标签在一个控制台内统一维护
目标二
批量运营
勾选对象后批量设置 / 移除分组与标签
目标三
列表可见
业务列表直接展示分组、标签并支持筛选
02

名词与概念

名词作用域说明
分组（Group）按业务对象类型隔离用于对同一类型对象做运营分层，例如「夏季主推」「节日礼盒」。一个对象可属于多个分组。
标签（Tag）按业务对象类型隔离用于对对象打标记，例如「热销」「促销」「进口商品」。一个对象可同时拥有多个标签。
品类（Category）商品商品自身的类目属性（如 BEVERAGE），由商品资料决定，不再与「分组」混用。
未分组 / 未打标签虚拟项非真实数据，用于统计未绑定任何分组或标签的对象数量，点击可筛出这批对象。
启用 / 停用分组、标签停用后不再出现在新建绑定候选中；已绑定的对象仍保留绑定关系，列表以「停用」标记提示。
设计原则：分组、标签按业务对象类型（预包装商品 / 现制商品 / 点位）相互隔离，同名标签在不同类型下互不影响。

详细需求 · 标签&分组管理

4.1入口与位置

  • 位于 系统设置 下的二级菜单，名称 标签分组管理 → 标签&分组管理。
  • 页面顶部提供对象类型切换 tab：预包装商品 / 现制商品 / 点位，切换后左侧与右侧数据同步切换。
  • 同时提供从业务页进入的入口：商品页右上角「分组&标签」按钮，进入后定位到对应对象类型。

4.3左栏：分组 / 标签维护

能力规则与交互
新建分组、标签分别有独立的「＋ 新建」；弹窗输入名称，名称在同一对象类型下唯一，重复时提示。
搜索分组、标签各有独立搜索框，按名称实时过滤当前类型下的列表。
列表项信息每项展示：启用 / 停用标记、名称、已绑定对象数量。
行内编辑列表项「⋯」→「编辑」进入行内编辑，Enter 确认、Esc 取消；改名同样做重名校验。
启用 / 停用「⋯」→「停用 / 启用」切换状态，更新时间为当天。
删除「⋯」→「删除」，需二次确认；删除后解除该分组 / 标签与所有对象的绑定。
未分组虚拟项置顶展示，显示「未分组 / 未打标签」的对象数量；选中后右侧列表只显示未绑定该项的对象。
单选筛选左侧选中一个分组或标签，右侧对象列表按该绑定关系过滤；再次点击取消选中即恢复全部。

4.4右栏：对象列表与批量操作

  • 列表列随对象类型变化，公共列为：复选框、对象主名称、状态、分组、标签；分组 / 标签列以胶囊标签展示，超过 2 个显示「+N」。
  • 表头复选框支持全选 / 反选当前筛选结果。
  • 勾选对象后，底部出现批量操作条：设置标签、移除标签、设置分组、移除分组、取消。
  • 设置类操作弹窗内可多选目标分组 / 标签，仅列出已启用项；移除类操作清除所选对象与所选分组 / 标签的绑定。
  • 批量操作完成后提示成功数量，列表即时刷新。

4.5规则与约束

  • 同类型下分组名、标签名均唯一，不同类型可同名。
  • 对象与分组、标签均为多对多关系，可绑定多个、也可完全为空。
  • 停用不解除历史绑定，仅在新建候选中隐藏，并在列表胶囊上标注「停用」。
  • 删除分组 / 标签属于破坏性操作，必须二次确认，并同步清理绑定关系。
  • 对象列表与绑定数量统计随操作实时更新，无需手动刷新。

5.3点位（本次仅约定规格）

点位页面本次未提供原型，以下为对齐约定，实现时按点位页既有规范落地。
  • 入口：页头新增「分组&标签」按钮，点击进入「标签&分组管理」并定位到「点位」类型 tab。
  • 列表：在既有列之后追加分组、标签两列，以胶囊展示，超过 2 个显示「+N」；未绑定时显示「—」。
  • 筛选：过滤区新增分组、标签两个筛选维度，仅列出已启用项，支持与其他筛选条件叠加。
  • 其他列：点位名称、所属租户、设备类型、运行状态保持现状，不在本次改动范围。

关键流程

7.1集中管理：给对象批量打标签

STEP 1
进入控制台
系统设置 → 标签&分组管理，选择对象类型
STEP 2
勾选对象
右侧列表勾选，或按左侧分组/标签先筛出对象
STEP 3
批量设置
底部操作条选择「设置标签 / 设置分组」并多选目标
STEP 4
即时生效
列表刷新、绑定数量更新，业务页同步展示

7.2业务页：按分组快速筛选

STEP 1
打开业务页
商品 / 预包装商品或现制商品
STEP 2
选择维度
过滤区选择「分组」或「标签」
STEP 3
查看结果
列表实时过滤，分组/标签列可见
STEP 4
清除条件
点击清除图标恢复全部

验收标准

编号验收项
AC-01系统设置下菜单、面包屑、页面标题均为「标签&分组管理」，无旧名称残留。
AC-02控制台可在预包装商品 / 现制商品 / 点位间切换，左右栏数据随之切换且互不串数据。
AC-03可新建、搜索、行内改名、启用/停用、删除分组与标签；重名被拦截，删除有二次确认。
AC-04「未分组 / 未打标签」数量准确，点击后只显示未绑定对象。
AC-05勾选对象后批量设置/移除标签与分组生效，绑定数量与列表即时刷新。
AC-06预包装商品页：列含分组、标签、更新日期、更新者；筛选含分组、标签、更新者；页头有「分组&标签」「+新建」。
AC-07现制商品页：列含分组、标签、租户与名称缩略图；筛选含分组；页头有「分组&标签」「+新建」。
AC-08点位页（实现后）：页头有「分组&标签」入口，列表展示分组、标签列，筛选支持分组、标签。
AC-09停用的分组/标签不进入新建候选，已绑定对象仍显示绑定并标注「停用」。
09

非目标与后续

  • 本次不涉及机器、租户对象的界面入口（数据层已具备类型隔离能力，可作为后续扩展）。
  • 本次不做分组 / 标签的排序拖拽、批量导入导出与权限细分。
  • 点位页面仅约定规格，界面实现与视觉细节在点位页开发时对齐。
  • 报表分析、组件管理、多语言本地化中的「分类」为独立业务概念，不在本次统一范围内。
