05

字段

字段 控件 必填 规则
转移方式单选是所有权转移：ownerTenantId 与 managerTenantId 同时变更；仅管理权转移：只变更 managerTenantId
目标租户下拉是仅列已启用租户；不可等于机器当前归属
转移原因下拉是销售交付 / 租赁交付 / 内部调拨 / 服务代管 / 其他
备注输入否≤ 100 字，写入转移单
支付厂家下拉否Stripe / Adyen / Billplz / Worldline；留空则交付后为待配置
结算币种下拉条件厂家已选时必填；默认取目标租户国家币种
库存处理单选是保留 / 清空；清空只改数量，货道与商品映射不变
应用配置单选是保留工厂配置 / 重置为接收方默认
落地点位只读—固定为目标租户默认点位「仓库」，工厂不可选投放点位
06

规则

边界
  • 目标租户未启用、或已是当前归属时，不可提交。
  • 只有工厂模式的机器可发起转移；转出后工厂侧只读。
  • 转移不可撤回，纠正需由接收方发起反向转移并重新审计。
  • 进行中工单随机器转交，编号不变。
数据
  • 支付通道与结算主体绑定租户，不随机器迁移；工厂代配的厂家与币种接收后可改。
  • 点位、货道布局、商品映射、IoT 规则、日志、固件随机器保留，不重建。
  • 清空库存写清库流水，记录操作人、时间、原数量。
  • 每次转移生成转移单与审计记录，含双方租户、方式、出厂配置快照。
