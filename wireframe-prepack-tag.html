提示：在现有「商品 / 预包装商品」设计稿基础上运行，请勿改动原有列与标题。

在「商品 / 预包装商品」现有列表页设计稿的基础上，仅新增「标签 / 分组」相关功能，其余所有列标题、表格布局与现有控件样式保持不变（不要改动：商品名称 / 租户 / 分类 / 品牌 / AI识别 / 状态 / 操作）。具体新增内容如下： 1. 顶部操作区：在原有「＋ 新建商品」主按钮左侧，新增两个次级按钮「分组设置」和「标签设置」，样式沿用现有次级按钮（非主按钮）。 2. 列表表格新增两列（位置：放在「状态」列之后、「操作」列之前）： · 「分组」列：展示该商品所属分组名称（胶囊/标签样式，可空，空时显示「—」）。 · 「标签」列：展示该商品的标签（多个标签以胶囊排列，可空显示「—」）。 3. 筛选区：在现有筛选条件下方/之后，新增「按标签筛选」与「按分组筛选」两个入口（沿用现有筛选条样式，可用下拉或多选 chip）。 4. 点击「标签设置」或「分组设置」后，在当前页面覆盖打开一个两栏设置页（不是跳转新页面）： · 左栏：标题「预包装产品 · 分组与标签」，右上「← 返回商品库」；下方两个区块「分组」「标签」，每块含搜索框 + 「＋ 新建」+ 列表项（每项：启用/停用徽标 + 名称 + 关联数 + ⋯菜单：编辑 / 启用·停用 / 删除）。左栏底部有「标签分组管理 ›」入口。 · 右栏：标题「预包装产品列表」，表格含复选列 + 商品名称 / 租户 / 分类 / 状态 / 分组 / 标签；勾选任意商品后，底部出现操作条：设置标签 / 移除标签 / 设置分组 / 移除分组 / 取消。 5. 弹层与抽屉（沿用现有弹窗样式，蓝色主按钮保持一致）： · 新建/编辑 标签(或分组)弹窗：名称(必填) · 适用对象(显示「预包装产品」，不可修改) · 已关联对象(数量 + 「查看关联对象」按钮) · 状态(启用/停用 单选) · 取消 / 保存。 · 设置/移除 标签(或分组)浮层：搜索框 + 可勾选列表 + 取消 / 应用。 · 查看关联对象抽屉（从右侧滑出）：展示该标签(分组)关联的商品表（列：产品名称 / SKU / 状态）+ 搜索框 + 关闭。 · 删除/停用 确认弹窗：说明影响范围（解除与 N 个对象的关联）+ 取消 / 确认删除。 约束：以上均为本次新增；原有列标题、宽度与现有视觉语言（按钮、表格、筛选条）请勿改动。
